우리악보 개인정보처리방침

시행일: 2026년 11월 9일

우리악보(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

앱은 개발자에게 어떤 개인정보도 전송하거나 수집하지 않습니다. 광고, 분석, 추적 도구를 사용하지 않습니다.

2. 기기에 저장되는 정보

  • 사용자가 가져온 악보 파일, 필기, 세트리스트, 녹음, 설정은 사용자의 기기에 저장됩니다.
  • iCloud 동기화를 켜면 같은 정보가 사용자 본인의 iCloud 계정에 저장되어 사용자의 다른 기기와 동기화됩니다. 이 정보는 Apple의 iCloud 약관에 따라 관리되며 개발자는 접근할 수 없습니다.

3. 기기 권한

  • 카메라: 종이 악보 촬영과 얼굴 동작 페이지 넘기기에 사용합니다. 영상은 기기 안에서만 처리하며 저장하거나 전송하지 않습니다.
  • 마이크: 연습 녹음과 튜너에 사용합니다. 녹음은 사용자가 선택한 악보에 첨부되어 기기(및 사용자 iCloud)에만 저장됩니다.
  • 로컬 네트워크: 같은 네트워크의 다른 기기와 페이지 넘김을 맞추거나, 사용자가 직접 입력한 WebDAV 서버에 연결할 때 사용합니다.
  • 사진: 사용자가 고른 사진만 악보로 가져옵니다.

4. 외부 서비스

사용자가 앱 안 웹 화면이나 WebDAV 서버를 이용하면, 해당 웹사이트·서버와 직접 통신합니다. 그 서비스의 개인정보 처리는 각 서비스의 방침을 따릅니다.
